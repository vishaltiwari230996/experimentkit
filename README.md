# ExperimentKit

STEM education chatbot for hands-on electronics kits. Flask backend with
LLM-powered Q&A (via OpenRouter), topic guardrails, and image support —
students ask questions about their kit and get grounded, curriculum-safe
answers.

Supports the **Karaoke Speaker Kit** and the **School Electronics Experiment
Kit**, each backed by its own JSON knowledge base.

## Stack

Python · Flask · OpenRouter LLM API · vanilla JS frontend · deployable to Vercel.

## Status

Working experiment, built for a client pilot. Not under active development.
